## Project Summary

Syndicati Web is the browser platform for residential community management. It connects residents, syndics, and administrators through residence management, apartments, events, complaints, forum discussions, messaging, notifications, secure authentication, AI assistance, and media handling.

The application is built with Symfony, Doctrine ORM, Twig, JavaScript, MySQL, Infisical-managed secrets, ImageKit media storage, and multiple optional service integrations such as mail, SMS, AI providers, WebAuthn, TOTP, and face authentication.
